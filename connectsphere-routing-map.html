🚨 What's Still Blocking Launch — In Order
1
Rebuild the app (Spark auth fix)
Code changes are saved but not built. Run expo start to test locally, or eas build for a real device.
cd artifacts/connectsphere-mobile → npx expo start
2
Trigger Render deploy (creates spark_memory DB table)
The buildCommand runs the DB migration automatically. Until this happens, Spark throws on 10+ message conversations.
Render dashboard → API server → Manual Deploy
3
App Store Connect IDs in eas.json
Replace REPLACE_WITH_APP_STORE_CONNECT_APP_ID and REPLACE_WITH_APPLE_TEAM_ID. Get from developer.apple.com → 20 minutes.
artifacts/connectsphere-mobile/eas.json
4
Firebase push config files
Without these, push notifications are completely dead. This kills re-engagement and tanks D7 retention before you even see it.
GoogleService-Info.plist (iOS) + google-services.json (Android) → Firebase Console → Project Settings
5
Cold-start walkthrough on real device
New account, no data. Walk every flow: sign up → discover → match → chat → events → Spark AI → premium. Write down every flinch. Fix those before submitting.
Do this before submitting to App Store
6
Play Store service account (Android)
Needed for eas submit to Android. Can do after iOS testing is confirmed working.
google-play-service-account.json → artifacts/connectsphere-mobile
