`CONNECTSPHERE_VERSION`

## Release Summary

ConnectSphere helps people meet through friend requests, plans, direct chats, and double-date matches with improved privacy, safety, and launch monitoring.

## What Changed

- Added in-app account deletion and data export request flows.
- Added consent-aware analytics and crash reporting hooks.
- Added report queue, abuse logging, rate limits, and broader block enforcement.
- Added feature flags for risky launch surfaces.
- Added EAS preview and production build profiles.

## Store Review Notes

- Account deletion is available from Settings > Privacy & Safety.
- Data export request is available from Settings > Privacy & Safety.
- Reports and blocks are available from user safety surfaces.
- Location, camera, photos, notifications, analytics, crash logs, auth, and payment SDK usage is documented in `privacy-data-inventory.md`.
