Rebuild ONLY the Connect tab into an Instagram-style Connections inbox.

Do not change any other tab, bottom nav, routing, auth, or app structure.

Design goal:
Make the Connect tab feel like Instagram DMs mixed with dating/networking/friends connections. Clean, addictive, fast, and social.

Core bug fix:
A match counts as a connection. Never show “No connections yet” if matches.length > 0.

Use this condition:
const shouldShowEmptyState =
  matches.length === 0 && conversations.length === 0 && requests.length === 0;

Layout:

1. Top header like Instagram DMs
- Left: “Connections”
- Right icons:
  - Search
  - New message
  - Filter/settings
- Subtitle small: “Messages, matches, and requests”

2. Search bar
- Rounded dark pill
- Placeholder: “Search connections”
- Filters results by name, intent type, or last message as user types

3. Story-style connection row
This should look like Instagram Stories.
Horizontal scroll bubbles:
- New Matches
- Active Now
- Dating
- Friends
- Networking
- Double Date
- Each bubble has gradient ring
- Profile image inside
- Small label below
- Online dot if active
- Tapping opens that connection or filtered group

4. Inbox tabs
Add Instagram-style segmented tabs:
- Primary
- Requests
- New Matches

Functionality:
- Primary shows conversations
- Requests shows pending friend/networking/dating requests
- New Matches shows people matched but not messaged yet
- Badge counts on each tab

5. Conversation list
Make it look like Instagram DM rows:
- Avatar left
- Name bold
- Last message preview
- Time on right
- Unread dot or unread count
- Online green dot
- Intent pill: Dating, Friends, Networking
- If unread, make row text brighter
- Swipe left options:
  - Pin
  - Mute
  - Delete

6. New Matches section
For users who matched but no message yet:
- Show as DM-style rows
- Text: “You matched — say hi 👀”
- Button: “Message”
- Tapping creates/opens chat

7. Requests section
For pending incoming requests:
- Avatar
- Name
- Intent reason
- Buttons:
  - Accept
  - Pass
- Accept moves them into Primary or New Matches depending on type

8. Chat actions
When opening a conversation:
- Send message
- Send emoji reaction
- Send quick opener
- Suggest date/hangout/networking plan
- Mark read
- Typing indicator
- Online status

9. Viral engagement features
Add these inside the Connect tab:
- “Active Now” row
- “New match” badges
- “Say hi before the vibe cools off”
- “Quick opener” button

Empty Primary:

Main logic:
const hasConnections =
  conversations.length > 0 ||
  matches.length > 0 ||
  requests.length > 0;

if (!hasConnections) show global empty state.
else show Instagram-style inbox.
